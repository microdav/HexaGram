# Documents statiques servis par l'application

Place ici la documentation PDF affichée dans l'application.

## Guide SSC-32U (FR + EN)

Les deux versions du guide officiel, aux noms **exacts** :

```
public/docs/lynxmotion_ssc-32u_usb_user_guide-fr.pdf
public/docs/lynxmotion_ssc-32u_usb_user_guide-en.pdf
```

Elles sont affichées dans la popin d'aide de la carte (onglet **Électronique → Architecture →
bouton « ? » sur la carte contrôleur → onglet « Documentation complète »**), avec un
sélecteur de langue Français / English.

Vite sert ce dossier à la racine du site : les fichiers sont accessibles aux URL
`/docs/lynxmotion_ssc-32u_usb_user_guide-fr.pdf` (et `-en.pdf`) et sont copiés tels quels
dans le build de production.
